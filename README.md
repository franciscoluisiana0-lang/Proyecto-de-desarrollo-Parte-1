### Descripción del proyecto
Este proyecto corresponde al análisis de información relacionada a cómo Argentina ha participado en el comercio internacion a lo largo de los últimos 

#### Proceso del proyecto

# A. Recolección y análisis de información
Se utilizó una de las herramientas sugeridas por el profesor (Claude) para el análisis la información adquirida a partir de los documentos de Excel y Word.

# B. Generación del sitio web
A partir del análisis realizado, se generó una pagina web en formato HTML.
El sitio contiene la información principal del trabajo de manera organizada y accesible.

# C. Publicación en GitHub
Se creó un repositorio público en GitHub.
En este repositorio se incorporó el material correspondiente al proyecto y el archivo HTML utilizado para la publicación.

# D. Publicación mediante Netlify
El repositorio de GitHub fue conectado con Netlify para realizar el despliegue del sitio web.
